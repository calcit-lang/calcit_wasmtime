# Formal Calcit 0.29.3 migration

Candidate 0.1.9 aligns with published Calcit 0.29.3 and makes both demo effects actually return their existing Unit contract. Public WAT formatting/execution inputs, checked results, errors and synchronous behavior remain unchanged.

Runtime/API behavior is unchanged; source changes add two demo Unit tails, alongside toolchain/module versions and root lock metadata. Rust FFI/runtime sources, dependencies, ownership, status mapping and original tests are preserved. Guarded Calcit transactions are used without casts, permissions, budgets or extra scripts. The publish and test workflows align the toolchain and replace deprecated CLI aliases with default strict checks and the same namespace scope. README.md separately documents user impact, validation commands and existing limitations.

Local checks passed: 9 definitions, 7 public definitions, strict workflow with zero diagnostics/suggestions, the original 2+3 Rust tests, fmt, all-target Clippy, Rust example result 47 and actual debug-library Calcit result 27/Unit. Version/free and both business exports are present. Remote clean Caps, release exports/build and exact-head CI/review remain pending; debug smoke is not release acceptance.

There is no frontend/COS. Heterogeneous EDN and unrestricted untrusted WAT remain explicit limitations; no new sandboxing or fully closed type claim is made.
