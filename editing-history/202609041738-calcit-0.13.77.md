# Calcit 0.13.77 / Calcit 0.13.77

## 中文

- 将项目要求的 Calcit 版本从 0.13.64 升级到 0.13.77，保持 Wasmtime API、模块版本和 C-safe FFI 契约不变。
- 将 CI 固定到支持独立 Caps 发布的 `calcit-lang/setup-calcit` v1 不可变 commit，启用 strict Caps，并将 workflow token 限制为只读内容权限。

## English

- Upgrade the required Calcit version from 0.13.64 to 0.13.77 while preserving the Wasmtime API, module version, and C-safe FFI contract.
- Pin CI to the immutable `calcit-lang/setup-calcit` v1 commit that supports independently released Caps, enforce strict Caps, and restrict the workflow token to read-only contents access.
