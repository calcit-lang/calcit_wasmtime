# 正式 Calcit 0.30.1 / Stable Calcit 0.30.1

使用者影响：开发与 Linux CI 使用正式 Calcit 0.30.1，不再配对 alpha；这是原生模块，无 procs 或前端部署。已发布 Git 0.1.10 保持原样，本提交不发版。macOS 正式 CLI 资产仍缺失，不把旧 alpha 的本地结果算作正式版验收。

只更新工具链声明、说明和现有 strict 门禁的结构化判定、完整定义检查；保留公共命名空间检查、Rust 测试、clippy、原生 ABI 审计及真实 demo。Snapshot、Rust / Cargo 依赖、buffer ownership、数值转换与错误合同不改。数值精度问题继续由 issue #24 跟踪，不加入编译器硬编码迁移规则或额外脚本。

User impact: development and Linux CI now select stable Calcit 0.30.1 instead of an alpha. This native module has no procs or frontend deployment. Published Git 0.1.10 remains untouched; this commit does not release. Stable macOS CLI assets are still absent, so earlier local alpha runs do not count as stable-version acceptance.

Only the toolchain declaration, documentation and existing structured strict/all-definition gates change. Public namespace checks, Rust tests, clippy, native ABI audit and the real demo remain. Snapshot, Rust/Cargo dependencies, buffer ownership, numeric conversions and errors are unchanged. Numeric precision remains tracked in issue #24, without compiler-specific rewrite rules or extra scripts.
