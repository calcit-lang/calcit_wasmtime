# 正式 Calcit 0.30.0 / Stable Calcit 0.30.0

时间 / Timestamp: 2026-10-16 06:12 UTC.

使用者影响：Git 模块候选 0.1.10 使用正式 Calcit 0.30.0。公开 WAT 格式化与
同步 i64→i64 执行、受检 String/Number 返回、错误传播和 C-safe ABI 不变。
Rust crate 仍为 0.1.9/publish=false；没有修改 Rust/Cargo.lock、原测试，
没有对不可信 WAT 增加资源限制，也不发布 crate。

User impact: module candidate 0.1.10 uses stable Calcit 0.30.0. WAT formatting,
synchronous i64→i64 execution, checked results, errors and the C-safe ABI are
unchanged. Rust crate 0.1.9 stays unpublished. No Rust source, lockfile,
original assertion or untrusted-code resource limit is changed.

测试与 release workflow 从 deps.cirru 选择相同 CLI，并以完整内置 strict workflow
替换普通可达检查。保留公开定义检查、Rust fmt/原测试/Clippy/原示例、release ABI
符号审计和实际 Calcit dylib demo；不新增脚本、规则、预算或 alpha pin。

Both workflows select the CLI from deps.cirru and replace the ordinary reachable
check with built-in complete strict verification. Original public checks, Rust
tests/example/Clippy, release symbol audit and actual Calcit dylib demo remain.
No checker script, rewrite rule, budget or alpha pin is introduced.

另将 get-dylib-ext 中一处已弃用 case-default 改为 match。官方 query/tree 确认
原节点后，用相同 transaction dry-run 和 scoped revision 守卫替换；所有 literal
映射和默认 .so 不变，不新增编译器规则。原生实际调用会覆盖本机后缀，Linux CI
覆盖 .so；不宣称 Windows runtime 验收。

One deprecated case-default in get-dylib-ext becomes match through a guarded
official transaction. Literal platform mappings and default .so are unchanged.
Actual native execution covers the host suffix; Linux CI covers .so, not a
claim of Windows runtime acceptance.
