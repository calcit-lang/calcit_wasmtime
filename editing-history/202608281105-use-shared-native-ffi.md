# 使用共享 native FFI crate / Adopt the shared native FFI crate

## 中文

- 用 `calcit_native_ffi 0.1.0` 替换本地 buffer layout、allocator ownership 与 Cirru EDN transport 模板。
- 保留 Wasmtime 业务执行和原有 0/1/2 status mapping。
- 增加双语维护与共享层边界文档。

## English

- Replace local buffer-layout, allocator-ownership, and Cirru EDN transport templates with `calcit_native_ffi 0.1.0`.
- Preserve Wasmtime business execution and the existing 0/1/2 status mapping.
- Add bilingual maintenance and shared-boundary documentation.
